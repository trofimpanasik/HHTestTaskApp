# 💳 HH — Тестовое задание

> **Важно:** Изначальное задание предполагало только вёрстку экранов. Однако я решил пойти дальше и реализовать полноценный функционал с Redux-стейтом, валидацией, навигацией и интерактивными элементами.

## 📱 Демонстрация

Приложение представляет собой клиент с:
- Главным экраном с балансом, категориями и историей операций
- Экраном добавления новой карты с валидацией
- Экраном уведомлений с фильтрами
- Переключением темы (светлая/тёмная)
- Bottom Tab навигацией

## 🚀 Установка и запуск

### Требования
- Node.js >= 20
- React Native CLI
- Xcode (для iOS)
- Android Studio (для Android)
- CocoaPods (для iOS)

### Шаги установки

```bash
# 1. Клонируйте репозиторий
git clone <repository-url>
cd HHTestTaskApp

# 2. Установите зависимости
npm install

# 3. Установите iOS поды (только для macOS)
cd ios && pod install && cd ..

# 4. Запустите приложение
# Для iOS:
npm run ios

# Для Android:
npm run android
```

## 🧪 Тестирование функционала

### Добавление новой карты

Для тестирования добавления карты используйте следующие данные:

| Поле | Значение |
|------|----------|
| **Номер карты** | `4532 0151 1283 0366` |
| **Срок действия** | Любая дата в будущем, например `12/27` |
| **CVV** | `123` (или `1234` для American Express) |

> ✅ Номер карты проходит Luhn-валидацию (алгоритм MOD10)

### Навигация по приложению

| Действие | Результат |
|----------|-----------|
| Нажатие на **аватар профиля** в шапке | Переход на экран уведомлений |
| Вкладка **Payments** | Можно добавлять тестовые операции |
| Вкладка **History** | Можно переключать тему (светлая/тёмная) |

## ✨ Реализованный функционал

### 🎨 UI/UX
- ✅ Pixel-perfect вёрстка по макету
- ✅ Адаптивный дизайн с SafeAreaView
- ✅ Тёмная и светлая темы
- ✅ Анимированные переходы между экранами
- ✅ Bottom Tab навигация с кастомными иконками

### 💳 Работа с картами
- ✅ Отображение карт с балансом и иконкой платёжной системы
- ✅ Добавление новых карт через форму
- ✅ Поддержка платёжных систем: Visa, Mastercard, Mir, UnionPay, American Express
- ✅ Валидация номера карты (Luhn/MOD10)
- ✅ Валидация срока действия
- ✅ Динамическая длина CVV (3 или 4 для Amex)

### 📊 Транзакции
- ✅ Группировка по датам (Сегодня, Вчера, дата)
- ✅ Отображение с иконками или аватарами
- ✅ Форматирование сумм и дат

### 🔔 Уведомления
- ✅ Фильтрация по категориям
- ✅ Пустое состояние при отсутствии данных

### 🗄 State Management
- ✅ Redux Toolkit для глобального состояния
- ✅ Типизированные хуки (useAppSelector, useAppDispatch)
- ✅ Слайсы для карт и транзакций

## 📝 Структура данных

### Card
```typescript
interface Card {
  id: string;
  cardNumber: string;
  expiryDate: string;
  cvv: string;
  paymentSystem: 'visa' | 'mastercard' | 'mir' | 'unionpay' | 'amex';
  cardType: 'debit' | 'virtual' | 'credit';
  balance: number;
  currency: string;
}
```

### Transaction
```typescript
interface Transaction {
  id: string;
  name: string;
  category: string;
  amount: number;
  date: string; // ISO string
  imageSource?: ImageSourcePropType;
}
```
